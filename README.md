# TIC MASTER — portail d'accès (GitHub Pages)

Ce dépôt public ne contient **que la page d'accueil** de TIC MASTER.
Il ne contient aucun code source, aucun secret et aucune donnée personnelle.

- URL publique : https://rzkmyazi.github.io/
- La page redirige automatiquement vers l'application Flask hébergée ailleurs.
- L'adresse de l'application est stockée dans `redirect.json` : modifiez ce fichier
  si le serveur change d'adresse, sans toucher à `index.html`.

Le code source complet de la plateforme reste dans le dépôt privé
https://github.com/rzkmyazi/tic-master
